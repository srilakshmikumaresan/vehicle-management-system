# 🚗 Vehicle Management System

## 📌 Overview
A full-stack Vehicle Management System developed using React, Spring Boot, and MySQL to manage fleet operations efficiently.

## ✨ Features
- Admin & Driver Login
- Vehicle Management
- Driver Management
- Vehicle Allocation
- Trip Management
- Fuel Tracking
- Maintenance Management
- Insurance & Document Alerts
- Live GPS Tracking
- QR Code Generation
- AI Maintenance Suggestions
- Dashboard Analytics
- PDF & Excel Report Export

## 🛠️ Tech Stack
- Frontend: React.js
- Backend: Spring Boot (Java)
- Database: MySQL
- Maps: Leaflet.js
- Authentication: JWT
